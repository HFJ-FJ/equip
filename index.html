导入整库备份（JSON）

可将线上系统导出的装备数据 JSON（或本系统之前导出的整库备份）导入本机。默认“合并追加”，不删除现有数据；勾选“整库覆盖”会清空现有数据后导入（谨慎）。

整库备份会把全部装备、审批、记录、账号与版本历史导出为 JSON，可用于迁移或离线存档。

真实 Git 仓库（浏览器内 · IndexedDB 持久化）

每次保存都会向浏览器内真实 Git 仓库提交一次（与上方"Git 式快照"并存）。仓库存于本机 IndexedDB，刷新或重开浏览器不丢失；可导出标准 .git（含真实 commit 对象）用于迁移，或推送到远程 Git 服务器（需服务器开放 CORS）。

云端同步（GitHub 共享数据）

把全部数据存到 GitHub 仓库的 db.json，所有设备读同一份 → 多人实时共享，无需服务器。建议仓库设为私有。先在 GitHub 生成一个对该仓库有“内容读写”权限的令牌(PAT)，粘贴到下方保存即可；之后每次保存自动上传。
